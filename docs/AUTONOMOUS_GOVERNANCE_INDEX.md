# Autonomous governance document index

This descriptive index records the current authority of repository governance
documents. It does not add routing, enforcement, risk calculation, or runtime
behavior. The machine-readable companion is
[`AUTONOMOUS_DOCUMENT_MANIFEST.json`](AUTONOMOUS_DOCUMENT_MANIFEST.json).

`AUTONOMOUS_DEVELOPMENT.md` is the current primary autonomy policy.
`AUTONOMOUS_ORCHESTRATION.md` and the autonomous-work issue template are
current subordinate autonomy orchestration contracts. The worker runbook,
troubleshooting guide, and Codex prompt guide are current reference material.
The Abaqus model contract is the current primary scientific-model contract.
Current A4 through A7 control-plane documents are subordinate autonomy
subsystem contracts. This index is current reference material, not policy.

Historical records and retained fixture evidence have no authority and are not
policy input, regardless of policy-like wording they may preserve. This
includes retained Terra and YELLOW canaries and issue-specific repair evidence.

For a worker's local validation before it commits, the first phase permits only
exact Git-reported authorized candidate additions. Once committed, the final
head phase requires every documented identity to be exactly Git tracked and
the candidate allowance is inactive. Equivalent phase wording is intentional;
the rule is about the two distinct identity states, not a required sentence.
